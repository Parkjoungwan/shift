# itch.io 페이지 디자인 기획

> 2026-11-27. 대상은 두 곳입니다. 하나는 게임 페이지 [nonoiseplz.itch.io/handover-shift-test](https://nonoiseplz.itch.io/handover-shift-test)이고(Game Off 2026 제출작), 다른 하나는 제작자 프로필 페이지 nonoiseplz.itch.io입니다. 게임 안의 아트 방향은 `../reports/인디 게임 그래픽 아트 디렉션.md`를 따릅니다.

## 1. 조사한 것

**itch가 허용하는 것 (테마 편집기)**
- 게임 페이지에서 로그인한 채 **Edit theme**을 누르면 바꿀 수 있습니다. 관리 화면(대시보드)에서는 못 바꿉니다.
- 바꿀 수 있는 것은 헤더(배너) 이미지, 배경 이미지, 색, 글꼴(본문과 제목 따로), 버튼 모양, 레이아웃입니다. [itch 공식 문서](https://itch.io/docs/creators/design), [새 테마 편집기 공지](https://itch.io/updates/a-new-theme-editor-for-project-pages)
- 배너는 테마의 일부라서 표지·스크린샷과 따로 올립니다. 배너를 올리면 설명 위의 제목 글자를 대신합니다(공식 문서 기준, 커뮤니티에서는 둘 다 보인다는 말도 있음).
- 배너 폭은 공식 문서상 최대 960px지만, 요즘 데스크톱에서는 1200px로 보여 960px짜리가 흐려진다는 보고가 있습니다. 그래서 **1200px 폭으로 만듭니다.** 배경 이미지는 3840×2160까지 됩니다. [hedgiespresso 이미지 가이드](https://hedgiespresso.itch.io/itch-page-image-templates)
- 표지는 630×500 권장이고, 3MB 이하 GIF도 됩니다. [jam 페이지 개선 글](https://pixelook.itch.io/death-is-only-the-beginning/devlog/390820/how-to-better-itchio-page-for-your-game-jam-submission)
- 사용자 정의 CSS는 itch 지원팀에 따로 요청해야 해서 이번에는 쓰지 않습니다. [CSS 가이드](https://itch.io/docs/creators/css-guide)
- 제작자 프로필 페이지도 같은 방식으로 헤더(이름 글자 또는 이미지·GIF)와 색을 바꿀 수 있습니다. [프로필 꾸미기 글](https://itch.io/blog/790882/customised-profile-page)

**잘 된 잼 페이지들의 공통점**
- 기본 흰 바탕 검은 글씨를 그대로 두지 않습니다. 첫인상에서 게임의 분위기가 보여야 합니다. [itch 블로그](https://itch.io/blog/34049/make-your-game-pages-beautiful-to-boost-your-sales)
- 게임 속 그림을 다시 써서 적은 노력으로 다듬은 페이지를 만듭니다. 헤더에는 가장 좋은 장면 하나를 씁니다. [Kenney: 잼 게임 발표 다듬기](https://kenney.nl/learn/improving-the-presentation-of-jam-games)
- 잼 주제를 모르는 사람을 위해 주제를 한 줄로 적습니다. 스크린샷이 본 페이지에서도 보이는지 확인합니다.

## 2. 방향: "책상 위의 서류"

게임의 화이트칼라 화면(관제 도면)이 그렇듯, 페이지 전체를 **어두운 책상 위에 놓인 인쇄 서류**처럼 만듭니다. 네온, 빛나는 테두리, 남색+청록 같은 흔한 기본값은 쓰지 않습니다(아트 방향 보고서의 금지 목록).

| 역할 | 색 | 게임 속 출처 |
|---|---|---|
| 배경 (책상) | `#1f1e1b` | 관제 화면 바깥 책상 `#2a2926`보다 한 단계 어둡게 |
| 본문 칸 (서류) | `#e9e4d6` | 도면 종이 |
| 글자 | `#1e1e1c` | 도면 잉크 |
| 링크 | `#b8302a` | 결재 도장 |
| 버튼 | `#e8b830` 위에 `#1e1e1c` 글자 | 안전 노랑 (HUD 「출근」 버튼) |

- **글꼴:** 제목은 고정폭(서식·타자기 느낌), 본문은 읽기 쉬운 산세리프로 둡니다. 편집기 목록에서 고릅니다.
- **배너 (1200×300):** 게임 속 현장 한 장면을 서류에 붙인 CCTV 사진처럼 두고, 옆에 서식 제목란처럼 「THE HANDOVER EXPERIMENT / 인수인계 실험」과 결재 도장을 놓습니다.
- **배경 (1920×1080, 반복):** 책상 표면입니다. 아주 옅은 나뭇결이나 철판 질감에, 구석에 서류 몇 장과 출근 카드, 커피 자국을 둡니다. 본문 칸에 가려지는 가운데는 비웁니다.
- **프로필 배너 (1200×300):** 「NONOISEPLZ」를 사원증·명판처럼 둡니다. 다른 두 게임(다녀왔습니다, 도깨비 장터)도 함께 보이는 곳이라, 이 게임 색을 너무 강하게 쓰지 않고 같은 책상 톤만 맞춥니다.

## 3. 만들 에셋

| 에셋 | 크기 | 만드는 법 |
|---|---|---|
| 게임 배너 | 1200×300 | Codex로 장면 그림(글자 없음)을 뽑고, 제목·도장은 코드로 얹습니다(이미지 생성은 글자가 자주 깨지기 때문) |
| 게임 배경 | 1920×1080 | Codex로 책상 질감(글자 없음, 가운데 비움) |
| 프로필 배너 | 1200×300 | Codex로 명판·사원증 배경(글자 없음), 이름은 코드로 |

**AI 고지:** 페이지 그림을 이미지 생성으로 만들면 itch의 AI 고지에서 **Graphics**도 체크해야 합니다. 게임 안 그래픽(3D 모델은 CC0 외부 에셋, 나머지는 코드로 그림)과 별개로, 페이지에 쓴 그림도 프로젝트의 일부로 봅니다.

## 4. 점검

- 배너와 제목 글자가 겹쳐 두 번 보이지 않는지 확인합니다.
- 본문 칸(크림색) 위의 링크·버튼 대비를 확인합니다.
- 게임 임베드(960×540)와 스크린샷이 본문 칸 안에 잘 들어가는지 봅니다.
- 휴대폰 폭에서 배너가 잘려도 제목이 읽히는지 확인합니다.
